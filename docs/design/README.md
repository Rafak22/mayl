# Mayl design reference (approved)
Static HTML mockups of the approved UI. They are the visual spec: match layout, colors, type and
content structure, but build real React components wired to the API (no copying of inline styles
wholesale, and no hardcoded demo numbers where real data exists).

Screens, in order: Overview.html (home) · Projects.html · ProjectMap.html (project view, map tab) ·
ProjectDetails.html (project view, data & solution tab) · Agents.html · Chat.html
